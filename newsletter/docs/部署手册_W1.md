#### SES Production Access 申请文案

```
Mail Type: Marketing
Website URL: https://taskon.xyz

We collect emails through landing pages (e.g., /benchmark-report) with explicit
opt-in. Each email includes:
- Unsubscribe link in every footer (CAN-SPAM)
- Physical company address
- List-Unsubscribe header (RFC 8058)
- DKIM/SPF/DMARC fully configured

Expected volume: ~3000 emails/month initially, scaling to ~10000/month over 6 months.

Complaint handling: AWS SNS webhook → immediate blocklist + alert.

We have 2000+ existing B2B contacts collected over 2 years through BD outreach
and historical paid customers.
```

#### VPS 初始化 SSH

```bash
ssh root@<vps-ip>
adduser taskon
usermod -aG sudo taskon
# 复制 SSH key
mkdir -p /home/taskon/.ssh
cat <Donald 的 public key> >> /home/taskon/.ssh/authorized_keys
chmod 600 /home/taskon/.ssh/authorized_keys
chown -R taskon:taskon /home/taskon/.ssh

# 禁用 root SSH + 密码登入（编辑 /etc/ssh/sshd_config）
# PermitRootLogin no
# PasswordAuthentication no
systemctl restart sshd

# 防火墙
ufw allow 22
ufw allow 80
ufw allow 443
ufw --force enable
```

#### Docker 安装

```bash
# 装 Docker（官方脚本）
curl -fsSL https://get.docker.com | sudo sh

# 加 taskon 用户到 docker 组
sudo usermod -aG docker taskon
# 退出重登

# 装 docker-compose v2 plugin
sudo apt update && sudo apt install -y docker-compose-plugin

# 验证
docker compose version
```

#### git clone VPS

#### DKIM/SPF/DMARC（同 v1）

**SPF**（TXT 记录 @）：
```
v=spf1 include:sendgrid.net include:amazonses.com ~all
```

**DKIM**（SendGrid 给 3 个 CNAME）

**DMARC**（TXT _dmarc）：
```
v=DMARC1; p=quarantine; rua=mailto:dmarc@taskon.xyz; pct=100
```

#### Donald 桌面 ingestion endpoint 部署

```powershell

cd D:\Taskon\marketing\engine\newsletter\webhook_server
pip install flask

# Ctrl+C 停止前台运行

# 5. 安装 nssm.exe（https://nssm.cc/download）注册为 Windows Service 开机自启

    "C:\Python312\python.exe" `
    "D:\Taskon\marketing\engine\newsletter\webhook_server\ingestion_endpoint_example.py"

# 配置环境变量
nssm set TaskOnNewsletterIngestion AppEnvironmentExtra `
    "WEBHOOK_SHARED_SECRET=<value>" `
    "SQLITE_PATH=D:\Taskon\marketing\00_内容营销引擎\runtime\state.db"

# 启动 service
```

#### Cloudflare Tunnel 配置（暴露 ingestion endpoint）

```powershell
# 1. 下载 cloudflared.exe 到 C:\Program Files\cloudflared\
# https://github.com/cloudflare/cloudflared/releases/latest

# 2. 登入
cloudflared tunnel login

# 3. 创建 tunnel
cloudflared tunnel create taskon-ingestion
# 输出 UUID

# 4. 配置文件 C:\Users\<user>\.cloudflared\config.yml
notepad C:\Users\<user>\.cloudflared\config.yml
```

```yaml
tunnel: <ingestion tunnel UUID>
credentials-file: C:\Users\<user>\.cloudflared\<UUID>.json

ingress:
  - hostname: taskon-ingestion.taskon.xyz
    service: http://localhost:5051
  - service: http_status:404
```

```powershell
# 5. DNS 路由
cloudflared tunnel route dns taskon-ingestion taskon-ingestion.taskon.xyz

# 6. 注册 Windows Service
cloudflared service install
```

#### Listmonk Webhook 配置

Listmonk UI → Settings → Webhooks → 添 4 条：

| Event | URL | Headers |
|---|---|---|
| campaign.send | `http://webhook_server:5050/listmonk/campaign_send` | 无需（Docker 内网） |
| campaign.open | `http://webhook_server:5050/listmonk/open` | 同上 |
| campaign.click | `http://webhook_server:5050/listmonk/click` | 同上 |
| subscriber.bounced | `http://webhook_server:5050/listmonk/bounce` | 同上 |

**URL 是 Docker 内部 DNS `webhook_server`，不是 `localhost`**。

## 常见异常（W1）

### 1. VPS 上 docker compose 启动失败

```bash
docker compose ps
docker compose logs <name>

# 常见原因：
#   - .env 中变量未填
#   - config/config.toml 语法错
#   - 端口被占用
```

### 2. Listmonk webhook → webhook_server 调不通

```bash
# 在 listmonk 容器内 ping webhook_server
docker compose exec listmonk wget -O- http://webhook_server:5050/health
```

### 3. VPS webhook → Donald 桌面 ingestion 调不通

```bash
# 在 VPS curl test
curl https://taskon-ingestion.taskon.xyz/health
# 应返回 200 + sqlite_ok

# 如失败：
# - 检查 Cloudflare Tunnel: cloudflared tunnel info taskon-ingestion
# - 检查 Donald 桌面 nssm service: nssm status TaskOnNewsletterIngestion
# - 检查 Windows Firewall 没拦 5051
```

### 4. 测试邮件进 Spam

按顺序排查（同 v1）：DKIM/SPF/DMARC PASS 检查 → DNS propagation → SendGrid Free 共享 IP 问题。

### 5. webhook 转发的事件没写进 SQLite

```bash
# 在 VPS 看 webhook_server 日志
docker compose logs -f webhook_server
# 看是否有"Forward failed"

# 看 JSONL 兜底文件
cat /opt/taskon-newsletter/data/webhook/failed_events.jsonl
```
