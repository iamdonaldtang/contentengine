## 0 · 上下文（为什么要做这次迁移）

### 0.1 · V1 起点（本会话 5/15 已上线）

```
[公网用户] → Cloudflare Edge → CF Tunnel (donald-local · cloudflared 在 Donald 笔记本)
            → localhost:5051 (engine ingestion) / localhost:8085 (shlink)

[Donald 笔记本] 上跑:
  ├─ engine + ingestion (docker)
  ├─ shlink (docker)
  ├─ Postiz (docker)
  ├─ MPT (docker)
  └─ cloudflared service
```

### 0.2 · V1.1 终点（本手册目标）

Donald 笔记本内存不够，把所有 docker 服务迁到公司局域网内**另一台 Windows 服务器笔记本**。Donald 自己笔记本通过 **Tailscale** 访问那台。

```
[公网用户] → Cloudflare Edge → CF Tunnel (donald-server · cloudflared 在服务器笔记本)
            → localhost:5051 (engine ingestion) / localhost:8085 (shlink)

[服务器笔记本] 跑:
  ├─ engine + ingestion (docker)
  ├─ shlink (docker)
  ├─ Postiz (docker)
  ├─ MPT (docker)
  └─ cloudflared service ★ 关键: 跟服务一起跑

[Donald 笔记本] 只跑:
  ├─ Cowork (Claude Desktop)
  ├─ 浏览器
  └─ Tailscale 客户端 → 访问服务器笔记本 (Postiz UI / SSH 跑 docker 命令)
```

### 0.3 · 关键决策（已拍板）

| 问 | 答 |
|---|---|
| ingest / l 走 CF Tunnel 还是 Tailscale？ | **CF Tunnel**·公网用户访问必须公网域名 |
| postiz / MPT 公网吗？ | **不公网**·Donald 自己用 → Tailscale 直连 100.x.x.x:4007 |
| cloudflared 装哪台？ | **服务器笔记本**·跟服务一起·少一跳·解耦 Donald 笔记本可关机 |
| 迁移路径选哪个？ | **B · 新建 donald-server tunnel**·运维 5min 换零中断 + 永久隔离 |
| 服务器笔记本 OS | **Windows 10/11** |
| Cowork 远程跑 engine 怎么走？ | **Tailscale SSH** · 零配置 + Tailscale 默认开 |

## 7 · Cowork 远程调 engine · Tailscale SSH 配置

### 7.1 · 服务器笔记本启用 OpenSSH Server（一次性 · 5min）

```powershell
# 服务器笔记本 · 管理员 PowerShell

# 装 OpenSSH Server (Windows 10/11 自带)
Add-WindowsCapability -Online -Name OpenSSH.Server~~~~0.0.1.0

# 启动 + 自启
Start-Service sshd
Set-Service -Name sshd -StartupType 'Automatic'

# 防火墙规则 (默认应该有 · 验证)
Get-NetFirewallRule -Name "*OpenSSH*"

# 验证 SSH 在跑
Get-Service sshd
# 期望: Status: Running
```

### 7.2 · 启用 Tailscale SSH（Tailscale 后台）

Donald 自己电脑浏览器开：

```
https://login.tailscale.com/admin/machines
```

找到 **服务器笔记本** → Edit → **SSH: Enable**

或者用 ACL 配置（高级 · 可不做）：
```

```

## 10 · 排错快查

| 现象 | 可能原因 | 修复 |
|---|---|---|
| `curl ingest.taskon.xyz/health` 502 Bad Gateway | cloudflared 在线但 ingestion 容器没起 / 不在 :5051 监听 | 服务器笔记本 `docker compose ps` 看容器 |
| `curl ingest.taskon.xyz/health` Could not resolve host | DNS 没更新 / tunnel 没起 | CF 后台 donald-server tunnel 状态 + 等 30s 重试 |
| 浏览器 free-diagnostic 看到旧错误页 | 浏览器缓存 | Ctrl+Shift+R 硬刷新 |
| 表单提交 CORS error | CORS_ALLOWED_ORIGINS env 没带过来 / 容器没读到 | 服务器笔记本 `.env` 检查 `CORS_ALLOWED_ORIGINS` · 重启 ingestion |
| Lark 群没收到 | LARK_WEBHOOK_URL 没带过来 | 服务器笔记本 `.env` 检查 |
| Tailscale SSH 进不去 | sshd 没装/没起 / Tailscale SSH 没在后台 enable | §7.1 + §7.2 |
| Postiz UI 访问超时 | postiz 容器没 listen 0.0.0.0 / 防火墙拦了 | `docker compose ps` 看 ports 是 `0.0.0.0:4007->5000/tcp` · 加防火墙入站规则 4007 |
| 双 connector 抢路由（A 方案才出）| donald-local 还在跑 | 立即 Stop-Service cloudflared 在 Donald 笔记本 |
