## 0 · Cowork 访问 4 种姿势速查

每个功能下面用 **A / B / C / D** 标注该用哪种姿势:

- **A · 文件系统**:Cowork 写或读 `runtime/drafts/<id>/*.md` / `runtime/*.json` / `runtime/*.md` — 无 API 调用
- **B · SQLite 直读**:Cowork artifact 内嵌 sql.js → 读 `runtime/state.db` (**read-only**,写永远走 engine job 或 ingestion)
- **C · ingestion HTTP**:Cowork fetch `http://127.0.0.1:5051/metrics` 或 `/health` 拿 Prometheus 数据 / 健康状态
- **D · engine CLI 触发**:Cowork 用 bash 工具跑 `docker compose exec engine python -m jobs.<xxx> ...`

### 1.8 短视频生产(MPT)· `jobs.mpt_runner` + `sources.mpt` ★ A-design async (2026-05-16 重构)

| 项 | 值 |
|---|---|
| 定位 | 读 `shorts_60s.md` → 提交 MPT 任务 → **1 秒内返回**(不阻塞);MPT 渲染完用 HMAC webhook POST 回 `/api/mpt-callback`;engine 异步下载 mp4 落 `drafts/<piece_id>/shorts_60s.mp4` |
| 触发 | cron `0 11 * * 1`(周一 11:00,adapter 出 shorts 之后) + 手动 + admin endpoint |
| 上游 | MoneyPrinterTurbo `http://host.docker.internal:8090`(本机已部署) |
| 状态机 | `mpt_tasks` 表:`pending_submit → submitted → completed/failed/stale` (原子 UPDATE + 幂等) |
| 兜底 | `jobs/mpt_reconciler` 每 5 分钟扫描 stuck submitted 行 → GET MPT 看 state → 自愈 simulate_callback。dropped callback 场景 ≤ 5min 内被 reconciler 救起。|
| 必填 env | `MPT_CALLBACK_URL`(default `http://taskon-ingestion:5051/api/mpt-callback`)、`MPT_CALLBACK_SECRET`(空 = 端点禁用 + mpt_runner 拒绝提交) |

**Cowork 访问**:
- **D · dry-run**:`docker compose exec engine python -m jobs.mpt_runner --piece-id 2026W19-thread01 --dry-run`
- **D · 真提交**(< 1s 返回):`docker compose exec engine python -m jobs.mpt_runner --piece-id 2026W19-thread01 --voice zh-CN-YunxiNeural-Male`
- **D · 强制重提交**(忽略 in-flight 幂等):同上加 `--force`
- **B · 监控状态**(SQL):`SELECT status, task_id, callback_received_at, completed_at, error FROM mpt_tasks WHERE piece_id='2026W19-thread01' ORDER BY id DESC`
- **A · 看产出**(callback 到达后落地):`runtime/drafts/<piece_id>/shorts_60s.mp4`

**⚠️ 已废弃 CLI 参数**:`--timeout`(旧 sync poll 用,async 后无意义,2026-05-16 commit `0912fa1` 删除)

### 10.1 · A-design 必填(2026-05-16 新增)

| Key | 用途 | 默认 / 说明 |
|---|---|---|
| **`MPT_CALLBACK_URL`** | MPT 回调 engine 的 URL | default `http://taskon-ingestion:5051/api/mpt-callback`(同一 docker network 时;跨 compose 项目时配 `host.docker.internal` 或 cloudflared 公网) |

| **`MEDIA_URL_BASE`** | 公开签名媒体 URL 的源 | `https://ingest.taskon.xyz`(走 cloudflared tunnel) |

| **`ADMIN_API_TOKEN`** | Cowork bash → admin endpoint Bearer | `openssl rand -hex 32` · 空 = `/admin/*` 401(禁用) |
