## 0 · Cowork 访问 4 种姿势速查

每个功能下面用 **A / B / C / D** 标注该用哪种姿势:

- **A · 文件系统**:Cowork 写或读 `runtime/drafts/<id>/*.md` / `runtime/*.json` / `runtime/*.md` — 无 API 调用
- **B · SQLite 直读**:Cowork artifact 内嵌 sql.js → 读 `runtime/state.db` (**read-only**,写永远走 engine job 或 ingestion)
- **C · ingestion HTTP**:Cowork fetch `http://127.0.0.1:5051/metrics` 或 `/health` 拿 Prometheus 数据 / 健康状态
- **D · engine CLI 触发**:Cowork 用 bash 工具跑 `docker compose exec engine python -m jobs.<xxx> ...`

### 1.5.2 KOL Custom Slice 触发器 · `jobs.custom_slice_generator` ★ T-02 (W23 · 2026-05-18 ship)

| 项 | 值 |
|---|---|
| 定位 | 每条 ①②⑤ piece 触发 1-3 个 KOL DM 草稿 · engine 起草,Donald 手发(B1 §6 红线 · NEVER auto-DM) |

**Cowork 访问**:

### 5.4 30-min 算法借力 Lark 提醒 ★ T-05 / T-07 (W22 · 2026-05-19 ship)

两条 nudge-only 任务,fire 后 Donald + 5-人 Reply 队伍立即上场 · engine **永远不替你发推 / 回评**。

| Job | cron | 触发条件 | 提醒目的 |
|---|---|---|---|
| `jobs.reply_density_alert` | `*/10 * * * *` | `platform LIKE 'x_%' AND scheduled_at BETWEEN now-31min AND now-29min AND reply_alert_sent IS NULL` | B3 §2 杠杆 1 · 5-人 Reply 队伍上场,每条 ≥30 字带新观点,不允许纯 +1 / Retweet |
| `jobs.linkedin_engagement_alert` | `*/10 * * * *` | `platform LIKE 'linkedin%' AND scheduled_at BETWEEN now-31min AND now-29min AND engagement_alert_sent IS NULL` | B3 §4 杠杆 1 · Donald 回 ≥5 条评论,LinkedIn 算法权重 10x |

**幂等机制**:`<col>_alert_sent` sentinel 列 · 2 分钟 fire 窗口(`now-31min` ~ `now-29min`)· 每 piece 每平台只 nudge 一次。

**MVP 限制**(T-05):**不**调 X API 查 reply 数 —— 因为 `external_post_id` 在 30min 时还 NULL(metrics_collector 20:00 才回填)。当前**总是 nudge**;未来要做"reply<5 才 nudge"需要 Postiz tweet_id 解析路径(TODO 在 `_should_skip_for_replies`)。

**Cowork 访问**:
- **D · 手动 fire(测试)**:
  ```
  docker compose exec engine python -m jobs.reply_density_alert
  docker compose exec engine python -m jobs.linkedin_engagement_alert
  ```
- **B · 看哪些 piece 已 nudge**:
  ```sql
  SELECT id, piece_id, platform, scheduled_at, reply_alert_sent, engagement_alert_sent
  FROM publishings
  WHERE reply_alert_sent IS NOT NULL OR engagement_alert_sent IS NOT NULL
  ORDER BY scheduled_at DESC LIMIT 20
  ```
- **B · 看心跳**:`SELECT * FROM heartbeat WHERE job_name IN ('reply_density_alert','linkedin_engagement_alert') ORDER BY last_run_at DESC LIMIT 6`

**红线**:engine 永不发 Reply / 永不评 LinkedIn · 只产生 Lark P2 提醒 + 写 sentinel(B1 §6 红线)。
