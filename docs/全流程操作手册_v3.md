# TaskOn 内容流水线 · 全流程操作手册 v3.0（2026-06-02 起生效）

> **本手册定位**：把内容「选题 → 起草 → 审稿 → 数据关 → 多平台改写 → 排程 → 真发 → 数据回流」做成**一条可随时启动、随时跑完的线性流水线**。

## 0 · v3 相比 v2 改了什么（必读）

| 变化 | v2（旧） | v3（新） |
|---|---|---|
| **engine 位置** | 主笔记本 docker 本机跑 | **引擎机 docker 远程跑**（Tailscale `engine` · 100.77.191.62） |
| **命令前缀** | `docker compose exec engine python -m jobs.xxx` | `ssh donald@engine "cd D:/engine-host/taskon/engine && docker compose exec -T engine python -m jobs.xxx"` |
| **文件路径** | `D:\Taskon\marketing\engine\runtime\drafts\<piece>\` | `\\engine\runtime\drafts\<piece>\`（SMB 共享）或 `Z:\drafts\<piece>\`（挂载盘符） |
| **入场检查** | `docker compose ps` | 主笔记本 `curl https://ingest.taskon.xyz/health` + SSH 跳转 `docker compose ps` |
| **HTTP 调用** | `http://127.0.0.1:5051/...` | `http://engine:5051/...`（Tailscale）或 `https://ingest.taskon.xyz/...`（公网带 Bearer） |
| **保留不变** | — | 13 步流程逻辑 / 4 个人工动作 / 4 条红线 / 异步配图+短视频 |

**一句话**：v3 把"主笔记本本地跑 docker"换成"主笔记本 Cowork + Tailscale SSH 远程操纵引擎机 docker"。**业务流程零变化，只是手柄变长了**。

## 0.6 · v3 命令封装 · `run_remote.ps1`（强烈推荐）

13 步里**每一步的 `ssh donald@engine "cd ... && docker compose exec ..."` 都很冗长**。我们把它封装成 `D:\Taskon\marketing\engine\scripts\run_remote.ps1`：

```powershell
# 旧（手写 v3 命令 · 90 字符）：
ssh donald@engine "cd D:/engine-host/taskon/engine && docker compose exec -T engine python -m jobs.adapter_orchestrator --piece-id 20260602-01"

# 新（封装后 · 60 字符）：
.\scripts\run_remote.ps1 -Job adapter_orchestrator -PieceId 20260602-01
```

### 5 种 Action 模式

| 模式 | 示例 | 用途 |
|---|---|---|
| `-Job <name>` | `-Job adapter_orchestrator -PieceId 20260602-01` | 跑 `python -m jobs.<name>` |
| `-Script <name>` | `-Script validate_selection -PieceId 20260602-01` | 跑 `python -m scripts.<name>` |
| `-Sqlite <SQL>` | `-Sqlite "SELECT id,email FROM leads LIMIT 5"` | 直接查 state.db |
| `-Compose <subcmd>` | `-Compose "ps"` / `-Compose "logs --tail 50 engine"` | docker compose 子命令 |
| `-Raw <cmd>` | `-Raw "Get-Date"` | 原样跑命令 |

### 智能特性

- **自动检测本机/远程**：如果脚本在引擎机上跑（本机有 `taskon-engine` 容器），自动转 Local 模式，省 SSH 开销
- **DryRun 模式**：`-DryRun` 只打印命令不执行（用于复制到别处跑或调试）
- **路径自适应**：默认 `D:/engine-host/taskon/engine`，可通过环境变量 `$env:REMOTE_ENGINE_DIR` 或 `-RemoteEngineDir` 覆盖

详见脚本头注释和帮助：

```powershell
Get-Help D:\Taskon\marketing\engine\scripts\run_remote.ps1 -Full
```

下面 §3 13 步都用 `run_remote.ps1` 简写。如果你想看等价的原始 SSH 命令，跑命令时加 `-DryRun` 即可看到。

## 6 · v3 红线（v2 基础上新增 2 条）

v2 4 条红线全部保留：
1. **数据关失败 = 砍**。绝不允许让 AI 改数字
2. **engine 永不自动发推 / 自动 DM**
3. **所有平台文案 + yt_metadata description 必须含 `{{CTA_URL}}` 占位符**
4. **选题拍板必须你来**

**v3 新增**：

5. **主笔记本永不再跑 docker** —— 任何 `docker compose up` 必须在引擎机执行，主笔记本只做 Cowork + SSH 跳转
6. **主笔记本永不再跑 cloudflared** —— 抢公网 tunnel 路由会让 production 链路飘忽
7. **跨网络 docker exec 必须经 Tailscale SSH，不要经 RDP** —— RDP 手工操作慢、易错，SSH 可脚本化、可重放

**保留的人工检查点**：审起草稿（步骤 4）、审配图（步骤 6）、数据关（步骤 5）、选题拍板（步骤 1.2）。

## 8 · v3 出错 cheatsheet（重点：远程化）

| 现象 | v3 命令 / 处理 |
|---|---|
| 引擎机不通 | 主笔记本 `ping engine` + `curl http://engine:5051/health`。两个都不通 → Tailscale / 引擎机宕机 |
| 公网不通 | `curl https://ingest.taskon.xyz/health` 502/Could not resolve → 引擎机 cloudflared service 挂 → SSH 跳转 `Start-Service cloudflared` |
| 容器健不健康 | `.\scripts\run_remote.ps1 -Compose "ps"` |
| 哪个 cron 挂了 | `.\scripts\run_remote.ps1 -Sqlite "SELECT job_name,last_run_at,status FROM heartbeat ORDER BY last_run_at DESC LIMIT 10"` |
| Cowork bash `docker compose exec` 报命令找不到 | 主笔记本本机没 docker。改用 `run_remote.ps1`（v3 红线 5）|
| `\\engine\runtime` 访问拒绝 | SMB 没共享 / 凭据没存。回 [enable_tailscale_ssh_and_smb.md Part B](../../../../TaskOn/infra/enable_tailscale_ssh_and_smb.md) |
| `tailscale ssh` 失败 "no SSH" | Tailscale ACL 没启用 SSH。回 [enable_tailscale_ssh_and_smb.md Part A](../../../../TaskOn/infra/enable_tailscale_ssh_and_smb.md) |
| 短视频卡死 | `.\scripts\run_remote.ps1 -Job mpt_runner -PieceId <id> -ExtraArgs "--force"` |
| voice 打回禁词 | Cowork 改 SMB 路径下的稿 → `.\scripts\run_remote.ps1 -Job voice_checker -PieceId <id>` |
| 删一条没用的 piece | 删 `Z:\drafts\<piece-id>\` + `.\scripts\run_remote.ps1 -Sqlite "DELETE FROM pieces WHERE id='<id>'"` |
| 容器日志 | `.\scripts\run_remote.ps1 -Compose "logs --tail 100 engine"` |
| 公网指标快查 | `curl https://ingest.taskon.xyz/metrics`（不需要 Tailscale · 浏览器也能看） |
| leads 总数验证 | `curl https://ingest.taskon.xyz/metrics | grep taskon_leads_total` |
